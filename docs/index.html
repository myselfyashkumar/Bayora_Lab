How it works

Six containers, each on its own private network with no internet. The gateway is the only door between them.

The demo, module by module

BLUE TEAMBlue's secret rules go into a sealed room that Red can never read.
RED TEAMRed attacks the model. Blocked replies look identical, whatever stopped them.
BREAKOUTRed tries to escape its container: other rooms, the internet, its own files. All blocked.
ATTACK SUITE35 automated attacks on our own system, across 10 categories.
AUDITA chained logbook signed by an independent notary. Change one entry and it's caught.
VERDICTFinal score, plus a visual report generated from the evidence.

Try it yourself

In your browser (nothing to install)

  1. Click Run it in your browser and sign in to GitHub.
  2. Click Create codespace and wait about 2 minutes.
  3. In the terminal, type make showcase.

On your own computer

  1. Install and start Docker Desktop.
  2. git clone https://github.com/myselfyashkumar/Bayora_Lab
  3. cd Bayora_Lab && bash run.sh
